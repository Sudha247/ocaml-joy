Getting started

You create a circle with this notation, where 50 units is the radius that you want.

let c = circle 50

Ignore the debug output val c : Joy_core.Shape.shape = ... for now, it will become clearer later.

Shapes don't render unless you ask them to be shown. Use show [c] to render the shapes.

show [ c ]

We use let _ = when we want to run a computation but don't need to keep the result. We run it and discard the value. The _ is by convention.

let _ = show [ c ]

Basic shapes

Joy supports basic shapes such as circle, ellipse, and rectangle.

let c = circle 50 let e = ellipse 75 50 let r = rectangle 100 75 let _ = show [ c; e; r ]

We are calling show with a list argument. Earlier the list had only one element. This list has three elements (c, e, r), separated by ;.

We can use let ... in to create values that are local to a block. This is useful when we don't need to refer to them later.

let _ = let c = circle 50 in let e = ellipse 75 50 in let r = rectangle 100 75 in show [ c; e; r ]

You can specify the center of a shape using the named argument ~c. point x y creates a point from integer coordinates.

let _ = let center = point 50 (-50) in let s = circle ~c:center 50 in show [ s ]

When the variable name matches the argument name, you can shorten ~c:c to just ~c.

let _ = let c = point 50 (-50) in let s = circle ~c 50 in show [ s ]

There is also line, which connects two points. ~a is the start point and b is the end point.

let _ = let a = point (-100) (-100) in let b = point 100 100 in let l = line ~a b in show [ l ]

Colors

You can color shapes with with_stroke and with_fill.

let _ = let c1 = circle 100 |> with_stroke red in let c2 = circle 50 |> with_fill red |> with_stroke transparent in show [ c1; c2 ]

The predefined colors are:

blackwhiteredgreenblueyellowtransparent

You can make custom colors with rgb or color (which also takes an alpha).

let _ = let c1 = circle 125 |> with_stroke red in let c2 = circle 100 |> with_stroke (rgb 0 200 0) in let c3 = circle 50 |> with_stroke (rgb 51 136 187) in show [ c1; c2; c3 ]

Combining shapes

You can group multiple shapes into one with complex.

let _ = let c = circle 50 in let r = rectangle 100 75 in let shape = complex [ c; r ] in show [ shape ]

Combining shapes is useful to apply transformations on the group. We'll look into transformations in the next section.

Transformations

Joy supports translate, rotate, and scale transformations.

translate moves a shape by x and y.

let _ = let c1 = circle 50 in let c2 = c1 |> translate 50 0 in show [ c1; c2 ]

|> is an OCaml operator that calls a function with the value on the left. c1 |> translate 50 0 is equivalent to translate 50 0 c1.

rotate rotates a shape anti-clockwise by the given angle in degrees.

let _ = let r = rectangle 100 75 |> rotate 45 in show [ r ]

scale resizes a shape.

let _ = let c = circle 100 |> scale 0.5 in show [ c ]

You can combine shapes and apply transformations on them together.

let _ = let donut = complex [ circle 50; circle 25 ] in let donut2 = donut |> scale 0.5 |> translate 125 0 in show [ donut; donut2 ]

Higher-order transformations

Joy supports the higher-order transformation repeat.

repeat applies a transformation multiple times and combines all the resulting shapes.

let _ = let b = point 0 100 in let l = line b in let shape = l |> repeat 18 (rotate 10) in show [ shape ]

Try changing the number of repetitions or the rotation angle.

let _ = let b = point 0 100 in let l = line b in let shape = l |> repeat 4 (rotate 30) in show [ shape ]

You can apply that on a square.

let _ = let r = rectangle 200 200 in let shape = r |> repeat 9 (rotate 10) in show [ shape ]

Or a rectangle.

let _ = let r = rectangle 200 100 in let shape = r |> repeat 18 (rotate 10) in show [ shape ]

Or even a circle.

let _ = let center = point 50 0 in let c = circle ~c:center 100 in let shape = c |> repeat 18 (rotate 20) in show [ shape ]

You can repeat multiple transformations together using compose.

let _ = let tx = compose (rotate 20) (scale 0.9) in let r = rectangle 200 200 in let shape = r |> repeat 72 tx in show [ shape ] let _ = let n = 72 in let angle = 360 / n in let tx = compose (rotate angle) (scale 0.92) in let r = rectangle 200 200 in let shape = r |> repeat n tx in show [ shape ]

You can create a spiral of circles.

let _ = let center = point 100 0 in let c = circle ~c:center 50 in let tx = compose (rotate 10) (scale 0.97) in let shape = c |> repeat (36 * 4) tx in show [ shape ]
